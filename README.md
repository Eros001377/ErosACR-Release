# Eros ACR（混淆版发布仓）

Eros 是基于 PromeRotation 框架的《最终幻想14》国服自动循环 ACR，当前支持两个职业：

- **武士（SAM）**：循环名「Eros 武士」
- **钐镰客（RPR）**：循环名「Eros 钐镰客」

本仓库只发布混淆后的二进制产物，不含任何源码。

## 功能特性

### 武士（SAM）

- 起手轴：100 级标准轴、2G 月彼轴，以及 90 / 80 / 70 级同步档起手轴，按等级自动分派
- 完整武士循环：居合（雪月花 / 五剑 / 彼岸花）、奥义斩浪、燕回返、闪影 / 红莲、照破、残心等
- 资源管理：明镜止水充能防溢出、剑气 / 剑压防溢出、彼岸花 DoT 续挂、身位自动修正
- 日随专属：Boss 上天自动默想、回返延后（团辅窗内憋爆发）

### 钐镰客（RPR）

- 单目标循环：神秘环 → 收割系（强化侧优先）→ 大丰收 → 夜游魂衣窗内连打 → 团契 / 完人爆发，灵魂切割控谱、隐匿挥割 / 暴食倾泻
- 资源管理：灵魂量谱防溢出、魂衣量谱以游戏高亮为口径、死亡之影 DoT 自动续挂、强化绞决 / 缢杀身位自动走向
- AoE 双阈值：3 目标与 4 目标自动切换对应循环
- 转场处理：目标不可选中自动预播魂种，日随脱战自动播魂种（QT 开关）

### 通用

- 自动防御：按职业配置静心 / 天眼通 / 内丹 / 浴血 / 牵制等（敌方读条死刑 / AOE 窗口触发）
- QT 面板开关、热键面板、身位绘制、自动真北等辅助功能

## 安装

1. 前置环境：国服客户端 + XIVLauncherCN + Dalamud + PromeRotation 插件。
2. 从 Releases 下载 `Eros.zip`。
3. 解压，将 `Eros` 文件夹放入：

   ```
   %APPDATA%\XIVLauncherCN\pluginConfigs\PromeRotation\ACR\
   ```

4. 启动游戏，切换到武士或钐镰客，在 PromeRotation 面板的循环列表中选择「Eros 武士」或「Eros 钐镰客」。

## 更新

下载新版本 `Eros.zip`，解压覆盖同名目录，游戏内重载插件后生效。
